# TIMER NASA
> Temporizador Web, de cuenta atrás estilo despegue de cohete, soporta segundos, minutos y horas, utilizando `setInterval()`.

---

## Demo En Vivo
> Demo en vivo desplegada en **GitHub Pages**:
https://migueldh137.github.io/Timer-NASA/

---

## Como Se Usa
- Ingresa en el link de la demo desplegada: https://migueldh137.github.io/Timer-NASA/

- Dependiendo del tiempo que se quiera contar hacia atrás, se ingresa la cantidad en  el input correspondiente:

- Una vez iniciado se podrá visualizar la cuenta atrás en la tarjeta con formato de reloj:

## Stack Tecnológico:
- **Lenguajes:**
  - **HTML5**: Estructura de la Web.
  - **CSS3**: Estilos y animaciones de la web.
  - **JavaScript ES6**: Dinamismo de la web con `querySelector` para seleccionar los elementos DOM, `evenListener` para los eventos de recoger la data de los inputs y activar la funcion de temporizador con `setInterval()`.
- **setInterval**:
  - Se utilizo la función de JS `setInterval` que permite ejecutar un bloque de código de forma repetitiva cada intervalo de tiempo determinado en mili segundos.
  - Documentacion: https://developer.mozilla.org/es/docs/Web/API/Window/setInterval
